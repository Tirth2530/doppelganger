        Safety without making humans approve everything

        The same labelled suite of 7 scenario classes, decided five ways. Every approach trades attacks stopped against legitimate work that interrupts a human. Only one reaches the top-left.

        Why this, why now

        OWASP Top 10 for Agentic Applications, 2026

        ASI03, Identity and Privilege Abuse: a low-privilege agent relays a request that a high-privilege agent executes without rechecking the user's original intent.

        Read the summary
        Supabase MCP, 2025

        Researchers showed a customer support ticket could steer a privileged coding agent into copying secret tokens back into the ticket. The same shape as our demo: outside content, a helpful agent, a privileged action.

        Read Simon Willison's write-up
        Prompt Infection, 2024

        Injected instructions spread from agent to agent inside multi-agent systems. A filter on one agent's input cannot see an instruction that arrives in a teammate's own words.

        Read the paper

        An error bound, not a promise

        Twins are random, so no single replay proves anything. The paired test's false-"influenced" rate is bounded by α at whatever round it stops (Ville's inequality), under the assumptions in the drawer. Stopping early to save tokens never loosens it.

        The Court is model-checked

        Every interleaving of requests, evidence callbacks, human decisions, commits, revocations, duplicates and retries, within bounds, run against the Court's real code. The replay worker and the humans are treated as untrusted.
